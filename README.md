# Portfólio Profissional — Luiz Eduardo (IA & Software)

> Portfólio web moderno e responsivo desenvolvido com **Vite + React 19 + TypeScript**, com identidade visual **Crimson Night**, animações de fundo interativo de rede neural e vitrine de projetos de Inteligência Artificial e Engenharia de Software.

---

## 🛠️ Tecnologias Utilizadas

- **Core:** React 19, TypeScript, Vite
- **Estilização & Design System:** Vanilla CSS com tokens visuais Crimson Night (`#050510`, `#dc143c`, `#ff4d6d`)
- **Tipografia:** Panic (Display), Retroica (Subtítulos), Nexa (Corpo)
- **Efeitos Visuais:** HTML5 Canvas 2D (Animação de Rede Neural em movimento com sinapses), Glassmorphism, Scroll Reveal
- **Ícones:** Lucide React & SVGs nativos

## 💻 Como Rodar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/luizedu0494/portifolio.git
cd portifolio
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no seu navegador em `http://localhost:3000`.
